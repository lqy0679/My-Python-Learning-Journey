# My-Python-Learning-Journey
廖青怡的 GitHub 仓库

## 项目简介
本仓库用来存放我的 Python 课程练习代码，目前有两个成绩判断程序，一个判断成绩是否及格，另一个将成绩划分为优、良、中、差四个等级，用于练习 `if…elif…else` 语句。

## 文件说明
- `score1.py`：成绩及格判断程序，输入分数，大于等于 60 输出及格，否则输出不及格。
- `score2.py`：成绩等级划分程序，输入分数，按 90、75、60 的分界输出优、良、中、差。

## 代码说明
```python
# score1.py 核心代码
score = int(input("请输入你的成绩: "))
if score >= 60:
    print("你的成绩合格")
else:
    print("你的成绩不合格")
```
使用 `if-else` 双分支结构，读取用户输入的分数，以 60 分为界限判断是否及格。

```python
# score2.py 核心代码
score = int(input("请输入你的成绩："))
if score >= 90:
    print("优")
elif score >= 75:
    print("良")
elif score >= 60:
    print("中")
else:
    print("差")
```
采用 `if…elif…else` 多分支，自上而下依次匹配分数区间，完成成绩等级划分。
